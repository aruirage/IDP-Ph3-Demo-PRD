# 产品定型摘要

## 本轮待审阅基线

定位：在现有 NeosAI IDP 上完成三期六个增量模块，不重新设计平台。

1. 更新：每日全量获取、只重建变化部分，支持手动追加／覆盖；同表串行。新增归属异常不启用，修改异常保留上一完整版本。获取不完整不生效；完整零条需当次管理员清空授权。已产生 OCR 结果保留快照。
2. 归属：使用官方 ICD-10 2013 本地分类；转换代码与名称精确对应，不使用类似度或模型。code 与名称精确对应分类冲突交管理员。其他树形数据可导入关系，普通数据无需层级。
3. 匹配：有照会 code 时精确和类似度同时执行；第一层 code、第二层 Top 3 校验、第三层已有模型兜底。无 code 或无命中时走类似度阈值及回溯。检索大于 75% 最多三条；表级自动采用默认 90%，范围 75%～100%。先阈值后回溯；不同深度对齐，唯一即停。平面数据沿用人工确认。
4. 输出：只回填账票第 3 步引用的主数据列；直接采用使用客户名称，回溯使用官方名称。符合规则自动覆盖字段 OCR 值，原文留存。人工修改最终优先，无候选也可改；只照合一次。
5. 容量：十万条客户记录，不含官方节点；超过容量整批失败，原数据不变。
6. QR：第 3 步既有规则增加全文／分隔、分隔符、序号。按分隔符筛来源；多个符合则按现有 prompt 和正解 OCR 抽出，不切分 OCR 结果。
7. 模型：既有模型设定统一主模型与验证模型，全局对所有账票生效，账票不重复维护。告警规则仍按账票维护；旧调用配置不在执行中切换。

视觉：沿用用户指定 manual 截图。桌面固定视口，现有侧栏、白底蓝色操作、紧凑表格及弹窗。

原型范围：配置、导入核对、更新、层级查看、匹配规则演示、OCR 确认、QR 配置、全局模型配置。后台行为以带标签的演示场景呈现。

状态：本摘要已整理，等待 G0 审阅；不标记为已批准。
