# 页面与流程构想

主数据列表 → 配置／列设置 → 导入 → 归属核对 → 正式数据与更新结果。
主数据列表 → 层级查看，按保存关系展示，不要求 SFDC 返回层级。
OCR 演示：精确匹配和 Top 3 并行 → 类似度校验精确值 → 不一致时已有模型兜底。
无精确结果：Top 3 → 表级阈值 → 未达且多候选时回溯；无层级则人工。
OCR 确认：原文和当前业务值同时展示；已有候选可选，人工可直接修改，无重新照合按钮。
账票类型第 3 步：QR 全文／分隔模式；只有 QR 路径使用分隔符和序号；OCR 兜底按字段 prompt 与正解抽出。
模型设定用途指派：OCR 主模型和验证模型全局生效；账票不再单独配置。

文档用左到右判定图说明规则；原型用场景切换演示自动采用、模型不可信、回溯唯一、人工、更新异常与容量失败。
